# Vimal & Kenal Wedding Album & Media Vault (V & K Media Vault)

A modern, luxury dark glassmorphism wedding web application and private media vault built with Node.js, Express, and Vanilla JavaScript & CSS.

## ✨ Features
- 👑 **Master Admin Dashboard:** Manage albums, upload photos & bulk videos, configure storage, and set album PINs.
- 👥 **Group / Guest PIN Protection:** Guests can enter album PINs (e.g. `1511`) to access dedicated private photo & video galleries.
- 💍 **Interactive Wedding Celebration Page:**
  - Dynamic 2x2 luxury countdown timer
  - Interactive event timeline & schedule
  - Live guest wishes wall & real-time guestbook
  - QR Passkey generator for camera auto-login
- 📱 **Mobile & Small-Screen Optimized:** 100% responsive touch layout with swipeable photo lightbox, 2x2 touch grids, and auto-zoom prevention.
- 🚀 **Google Drive Integration:** Import videos and photos directly from Google Drive share links.

## 🚀 Quick Start

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the server:
   ```bash
   npm start
   ```
   Or run with Node:
   ```bash
   node server.js
   ```

3. Open in browser:
   - Media Vault & Admin: [http://localhost:3000](http://localhost:3000)
   - Wedding Celebration Page: [http://localhost:3000/wedding.html](http://localhost:3000/wedding.html)
